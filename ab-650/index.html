O exame num relance

O AB-650 junta a administração clássica do Microsoft 365 com a nova camada de IA: Copilot, agentes, Agent 365 e o Copilot Control System. Quase metade do exame é identidade, segurança e Purview. Cada bloco abaixo tem a largura do seu peso no exame. Clique para estudar.

The exam at a glance

Perfil do candidato

Configura, gere, protege e governa tenants Microsoft 365, workloads e serviços de IA (Copilot, agentes e capacidades de IA ligadas ao tenant). Trabalha com arquitetos e administradores de identidade, segurança, compliance, endpoints e aplicações.

Experiência recomendada

  • Workloads do Microsoft 365 (Exchange, Teams, SharePoint, OneDrive)
  • Microsoft Entra ID
  • Capacidades do Defender XDR
  • Microsoft Graph PowerShell

Âmbito das questões

A maioria das perguntas é sobre funcionalidades GA. Funcionalidades em preview podem aparecer se forem muito usadas. O Agent 365 e o Cowork mudam depressa, por isso confirme as definições no portal.

Candidate profile

Configures, manages, secures and governs Microsoft 365 tenants, workloads and AI services (Copilot, agents and connected AI capabilities). Works with architects and administrators across identity, security, compliance, endpoints and applications.

Recommended experience

  • Microsoft 365 workloads (Exchange, Teams, SharePoint, OneDrive)
  • Microsoft Entra ID
  • Defender XDR capabilities
  • Microsoft Graph PowerShell

Question scope

Most questions cover GA features. Preview features can appear if they're commonly used. Agent 365 and Cowork change quickly, so check the settings in the portal.

Onde se perdem pontos

  • Saber o que uma funcionalidade faz mas não onde se configura
  • Confundir o portal certo (admin center vs Entra vs Purview vs Defender)
  • Escolher Global Admin quando há uma função de menor privilégio

Estratégia de estudo

  • Domínio 2 primeiro: vale quase metade do exame
  • Percorrer as definições de Copilot, Agent 365 e SAM num tenant de teste
  • Graph PowerShell: módulos atuais e como ligar a cada serviço

Durante o exame

  • O Microsoft Learn está disponível, mas não dá tempo extra. Use-o só para confirmar
  • Leia o requisito decisivo: "least privilege", "without changing access", "first"
  • Desconfie das opções com "always", "automatically" ou "all"

Where points get lost

  • Knowing what a feature does but not where it's configured
  • Mixing up the right portal (admin center vs Entra vs Purview vs Defender)
  • Picking Global Admin when a least-privileged role exists

Study strategy

  • Domain 2 first: it's almost half the exam
  • Click through Copilot, Agent 365 and SAM settings in a test tenant
  • Graph PowerShell: current modules and how to connect to each service

During the exam

  • Microsoft Learn is available, but there's no extra time. Use it only to confirm
  • Read the deciding requirement: "least privilege", "without changing access", "first"
  • Be wary of options with "always", "automatically" or "all"
