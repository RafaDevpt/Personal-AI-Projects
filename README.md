# Personal-AI-Projects
A collection of personal AI projects that I have developed to automate tasks, improve productivity, and assist with both professional and personal activities.

 
## Branch Strategy
Rather than creating separate repositories, each AI project is organized within its own dedicated branch:

- `main` – Repository overview, documentation, and project index.
- 
- Project branches – Individual AI projects with their own codebase and documentation.
 
This approach keeps all projects centralized while allowing each one to evolve independently.
