Onde se perdem pontos

  • Confundir o que é determinístico (hooks, permissões, definições) com o que é só uma instrução (CLAUDE.md, prompts)
  • No Enterprise, esquecer que a regra da união faz ganhar sempre a permissão mais larga
  • Na API, esquecer que a API não guarda estado: o histórico vai todo em cada pedido

Estratégia de estudo

  • Faça os exercícios com um projeto real: um script seu no Claude Code, uma chamada à API em Python
  • No Enterprise, preencha o work-along companion com a sua empresa à medida que avança
  • Use o separador Treino no fim de cada curso, e a Referência rápida antes do quiz

Nos quizzes

  • Procure a palavra decisiva: "determinístico", "sem perder contexto", "irreversível", "menor custo"
  • Desconfie de respostas que dão mais acesso, mais modelo ou mais contexto do que a tarefa pede
  • Na dúvida entre duas, escolha a que se pode desfazer

Where points get lost

  • Mixing up what's deterministic (hooks, permissions, settings) with what's only an instruction (CLAUDE.md, prompts)
  • In Enterprise, forgetting that the union rule means the broadest permission always wins
  • In the API, forgetting the API is stateless: the whole history goes in every request

Study strategy

  • Do the exercises on a real project: one of your scripts in Claude Code, an API call in Python
  • For Enterprise, fill in the work-along companion with your own company as you go
  • Use the Practice tab at the end of each course, and the Quick reference before the quiz

In the quizzes

  • Look for the deciding word: "deterministic", "without losing context", "irreversible", "lowest cost"
  • Be wary of answers that grant more access, more model or more context than the task needs
  • When torn between two, pick the one you can undo

O ciclo do tool use, num pedidoThe tool use loop, in one request

import anthropic
client = anthropic.Anthropic()          # lê ANTHROPIC_API_KEY do ambiente / reads it from the environment

messages = [{"role": "user", "content": "Há quartos livres a 24/12?"}]
tools = [{
  "name": "check_availability",
  "description": "Devolve os quartos livres para uma data (AAAA-MM-DD).",
  "input_schema": {"type": "object",
                   "properties": {"date": {"type": "string"}},
                   "required": ["date"]}
}]

while True:
    resp = client.messages.create(model=MODEL, max_tokens=1024,
                                  messages=messages, tools=tools)
    messages.append({"role": "assistant", "content": resp.content})   # guarda o tool_use
    if resp.stop_reason != "tool_use":
        break
    results = []
    for block in resp.content:
        if block.type == "tool_use":
            out = run_tool(block.name, block.input)                    # a SUA função
            results.append({"type": "tool_result",
                            "tool_use_id": block.id, "content": out})
    messages.append({"role": "user", "content": results})
