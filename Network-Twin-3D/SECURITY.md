## Supported versions

Only the latest version of Network Twin 3D on the `network-twin-3d` branch receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting on the hub repository instead:
**Security → Report a vulnerability**
(<https://github.com/RafaDevpt/Personal-AI-Projects/security/advisories/new>), and mention *Network Twin 3D* in the title.

Include the version, the platform (Windows, Linux or macOS), the steps to reproduce and the impact you expect. You will get an answer within 7 days; fixes are released as a new version and credited in the CHANGELOG unless you prefer otherwise.

## Your own data

A Network Twin 3D project joins the network map, the designed configuration, the floor plans and the physical location of every rack. Treat it as confidential: keep real projects outside any repository. The `.gitignore` blocks them as a second line of defence; only the synthetic example belongs here.
